2. Clique no + (canto superior direito) > New repository.
3. Repository name: braco-simulador-grupo7
   Marque Public. Marque Add a README file. Clique em Create repository.
4. Na página do repositório: Add file > Upload files.
5. Abra a pasta SITE_GRUPO_7 no computador, selecione TODOS os arquivos de dentro dela

    "Ver em realidade aumentada" (Android: Chrome; iPhone: Safari).
